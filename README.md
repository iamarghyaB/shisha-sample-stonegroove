# SHISHA SAMPLE — Stone Groove-inspired design demo

An independent static website demonstration by **OCTETEC × MAKEZAA**. This is not an official venue website.

## View locally

Double-click `index.html`. All 13 HTML pages, images, fonts, videos, styles and scripts use relative local paths. No server, installation or build step is required.

## Hosting

This repository contains only this design. It can be deployed directly as a static Vercel project. The included `vercel.json` disables framework detection, installation and building, and serves the repository root. Local Vercel project metadata is ignored by Git.

## Assets and demo behaviour

Original reference photographs, artwork, responsive image variants and available media are included locally under `assets/`. Asset URLs are recorded in `assets/sources.json`; open-source font licenses are in `assets/fonts/`. The user confirmed permission for public GitHub publication and public Vercel hosting on 21 November 2026. Original names may remain within photographs or product artwork; live interface branding is SHISHA SAMPLE.

The shared agency introduction lasts approximately two seconds. Navigation, galleries and demo forms run locally. Booking, ordering, contact and mailing-list forms do not send or save personal information, make reservations or process payments. Third-party live service integrations and trackers are not included.

## Verification

The three-design suite passed 105 offline Chromium layout checks across 21 pages at 1440, 1024, 768, 390 and 375 pixels. Menus, galleries, local video playback, form previews and loading fallbacks were tested.
